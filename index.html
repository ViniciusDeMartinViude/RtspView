Only have an RTSP URL?

Run the included mediamtx.yml gateway configuration on a computer that can access the camera. Set MTX_PATHS_CAMERA_SOURCE to your original RTSP address. For this HTTPS GitHub Pages site, expose the gateway through a secure HTTPS endpoint with HLS/CORS configured, or a WebRTC player that permits iframe embedding. A LAN-only http://192.168.x.x gateway cannot normally be loaded directly by this HTTPS site. See the setup guide.
